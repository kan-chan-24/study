# vimrcについて
## vimrcの場所
- ~/.vimrcに置いてある
- vimの設定をここに書いておくと、記入後のvim起動時に反映される

## ファイルの検索範囲を深くしてみた
- :find コマンド（プラグイン不要）

```
:find ファイル名
```

- path というオプション（検索対象のディレクトリ）に登録された範囲からファイル名を探して開いてくれる。
- 途中まで打って Tab キーを押すと、候補が補完される（複数候補があれば Tab を連打して選べます）。
- デフォルトだと現在のディレクトリしか探せないことが多いので、事前に以下を設定しておくと便利

```
:set path+=**
```

- これを .vimrc に書いたことで、サブディレクトリも含めて再帰的に探してくれるようになった（** が「配下すべて」の意味になる）。
