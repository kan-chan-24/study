# vimrcについて
## vimrcの場所
- ~/.vimrcに置いてある
- vimの設定をここに書いておくと、記入後のvim起動時に反映される

## ファイルの検索範囲を深くしてみた
- :find コマンド（プラグイン不要）

```
:find ファイル名
```

- path というオプション（検索対象のディレクトリ）に登録された範囲からファイル名を探して開いてくれる。
- 途中まで打って Tab キーを押すと、候補が補完される（複数候補があれば Tab を連打して選べます）。
- デフォルトだと現在のディレクトリしか探せないことが多いので、事前に以下を設定しておくと便利

```
:set path+=**
```

- これを .vimrc に書いたことで、サブディレクトリも含めて再帰的に探してくれるようになった（** が「配下すべて」の意味になる）。

# vimの移動コマンドまとめ

### 文字単位移動

- h: 左に移動
- j: 下に移動
- k: 上に移動
- l: 右に移動

### 単語単位移動
#### 記号区切り
- w: 単語分先へ移動
- b: 単語分前へ移動
- e: 単語の末尾へ移動

#### 空白区切り
- W: 空白区切りの単語分先へ移動
- B: 空白区切りの単語分前へ移動
- E: 空白区切りの単語の末尾へ移動

### 行/文/段落単位移動
- 0: 行頭へ移動
- ^: 空白以外の行頭へ移動(インデントとか)
- $: 行末へ移動
- ): 文分上に移動
- (: 文分下に移動
- }: 段落分上に移動
- {: 段落分下に移動

### 行指定移動
- {num}G: {num}行目に移動
- :{num}: {num}行目に移動
- gg: 1行目に移動
- G: 最後の行に移動

### 画面単位移動
- ctrl-b: 画面分上に移動
- ctrl-f: 画面分下に移動
- ctrl-u: 画面の半分上に移動
- ctrl-d: 画面の半分下に移動
- H: 画面内の最初の行に移動
- M: 画面の中央の行に移動
- L: 画面内の最後の行に移動
